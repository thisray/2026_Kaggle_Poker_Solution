# Round 19 handoff builder

build_handoff.sh packages the Round 19 state snapshot, accumulated Markdown research documents, Round 19 scripts, and JSON receipts for external review.

The builder excludes raw competition data, model weights, credentials, and submission artifacts. It writes /Users/vegapunk/Downloads/Poker_Round19_Handoff_20260919.zip and creates an inner SHA256SUMS.txt manifest.
